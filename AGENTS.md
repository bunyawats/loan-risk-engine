# AGENTS.md

This file provides guidance to Codex and other coding agents working in this repository.

**Read [`CLAUDE.md`](CLAUDE.md) and follow it.** Despite its name, it is the single source of guidance for every agent: the HTTP contract, the invariants I1–I5, configuration, rules, Jev, logging, testing, and working conventions. It is kept up to date; this file is not copied from it, so it cannot drift.

Then read `SPEC.md` (the full design; `CLAUDE.md` wins where they differ) and `IMPLEMENTATION_PLAN.md` (current status, open decisions, and the Session Log).
